## What NumTrip is

NumTrip is a number combination game in which the goal is to get to the number 256. You achieve this by clicking on same numbers that are next to each other. By doing so, the number doubles and the "number cloud" disappears. When there are no more options or you reached 256, the game ends.

## Why I built it

This game was an assignment in the supplementary subject "Informatics" in high school. The game was pre-defined and the guidelines were set. The goal was to learn basic algorithms, learn python and look at programming strategies.

## How it works

The game uses the floodfill() algorithm to fill the board with random numbers in the beginning and each time a number-cloud is clicked. Also implemented is a gravity() algorithm that makes sure the free spaces after combination get filled by the numbers above.

## What I learned

Programming this game I learnt the fundamentals of python programming. I learned how to plan a project top-down. How to implement different algorithms and how to go about debugging something that does not work. At the same time, github was brought closer and I learnt that documenting the process is as important as the coding itself.

## What I'd do differently today

Looking back at the code a few years later, there is probably a lot I would change in the structure, variables and documentation process. What is also important to note is that at that time, AI was not an option yet and everything was done by hand. This makes this first project even more special looking back.
